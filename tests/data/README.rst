Test Data
=========

All the test data included in this directory (incl. subdirectories) is
originally created by CSC - IT Center for Science Ltd unless otherwise stated.

Test file ``image_jp2/valid__jpylyzer_reference.jp2`` is from `Jpylyzer test files <https://github.com/openpreserve/jpylyzer-test-files>`__ and reduced in size.

Test file ``image_tiff/valid_1.1_geotiff.tif`` was downloaded from the `National Land Survey of Finland open map images and raster datasets <https://asiointi.maanmittauslaitos.fi/karttapaikka/tiedostopalvelu>`__ (Elevation model 2m - GeoTIFF) on 06/2026, available under Creative Commons Attribution 4.0. All invalid GeoTIFF 1.1 files are edits of this file.

Test file ``image_tiff/valid_1.1_geotiff_multichannel_32bit.tif`` was derived from ``diversity_change_total_CEREALS.tiff`` in the Zenodo dataset `Data from: Climate change threatens crop diversity at low latitudes <https://zenodo.org/records/14801623>`__ by Sara Heikonen, Matias Heino, Mika Jalava, Stefan Siebert, Daniel Viviroli and Matti Kummu, downloaded on 07/2026. Available under Creative Commons Attribution 4.0.
