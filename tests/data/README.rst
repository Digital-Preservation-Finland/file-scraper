Test Data
=========

All the test data included in this directory (incl. subdirectories) is
originally created by CSC - IT Center for Science Ltd unless otherwise stated.

Test file ``image_jp2/valid__jpylyzer_reference.jp2`` is from [Jpylyzer test files](https://github.com/openpreserve/jpylyzer-test-files) and reduced in size.

Test file ``image_tiff/valid_1.1_geotiff.tif`` was downloaded from the [National Land Survey of Finland open map images and raster datasets](https://asiointi.maanmittauslaitos.fi/karttapaikka/tiedostopalvelu) (Elevation model 2m - GeoTIFF) on 06/2026. All invalid GeoTIFF 1.1 files are edits of this file.
